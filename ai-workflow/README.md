# AI development workflows

This folder documents the global routed-agent workflows for Claude Code and Codex.

- [Claude Code](./claude/README.md): global Claude instructions, agents, setup, and verification.
- [Codex](./codex/README.md): global Codex instructions, specialist TOML files, the `project-workflow` skill, and new-workstation setup.

Both workflows route conditionally. Their model settings and available specialist roles are client-specific; use the setup guide for the client you are installing.
